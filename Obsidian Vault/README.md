# Research Vault

这个仓库已经初始化为 Obsidian 文献-笔记管理系统。

## 目录结构

- `00_Inbox/`：临时入口
- `10_Literature/`：文献笔记，含 `Papers/`、`Surveys/`、`Books/`
- `20_Field_Maps/`：领域地图与文献面板
- `21_Question_Maps/`：问题地图
- `30_Methods/`：方法笔记
- `35_Datasets_Benchmarks/`：数据集与 benchmark
- `40_Candidate_Topics/`：候选选题
- `50_Projects/`：正式项目
- `60_AI_Context/`：AI 工作流隔离区
- `90_Templates/`：模板库
- `99_Attachments/`：附件区
